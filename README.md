# wytham-tits-fly
https://doi.org/10.5281/zenodo.19498793


- This code models spontaneous, non-steady-state take-off flights of wild mixed flock tit species. The data inclusdes 1434 spontaneous flights from 49 individuals of great tits (Parus major), blue tits (Cyanistes caeruleus), and marsh tits (Poecile palustris) in the Paridae family, measured using two automated RFID-infrared tunnels.
  
- Use natural-var_final.Rmd to run all the codes. The raw data files required to run the full codes are 'all_dates3.txt', 'caught.hour.day.csv', and 'climate_filled.csv'.
