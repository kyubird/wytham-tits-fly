# wytham-tits-fly
https://doi.org/10.5281/zenodo.8475

This code shows interspecific difference in flight performance in mixed flock tit species, namely blue tits, great tits, and marsh tits. 
Use natural-var_final.Rmd to run all the codes. The data files required to run the full codes are all_dates3.txt, caught.hour.day.csv, and climate_filled.csv.
